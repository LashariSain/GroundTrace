Know which vulnerabilities and threats to deal with first.

GroundTrace is a self-hosted threat-intelligence tool. It collects public vulnerability and threat data, ranks it by what attackers are really doing, and tells you plainly when the evidence isn't good enough.

See what it does ↓

The questions it answers

Thousands of vulnerabilities are published, and a severity score alone doesn't say which ones are being attacked. GroundTrace brings the evidence into one place.

shield

What should I patch first?

Ranks CVEs using severity, predicted exploitation and CISA's list of known exploited vulnerabilities, and shows how each score was calculated.

search

Is this IP, domain or hash known?

Look up a suspicious indicator to see what has been recorded about it and which known group's habits it resembles, if any.

radar

What is gathering attention?

Ranks CVEs not yet on CISA's list by rising exploit predictions, reporting and public exploit code. It's a ranking, not a forecast.

public

Where is attack infrastructure hosted?

Maps malicious infrastructure by country and provider, so you can see where to block. It shows hosting, not who is behind an attack.

bug_report

Is exploit code public?

Lists public exploits for a CVE and flags repositories that look like traps. Links only: nothing is downloaded or run.

notifications

What changed since I last looked?

A background watcher raises alerts for new known-exploited CVEs and for matches on the products you choose to watch.

Who it's for

People who need to make security decisions from evidence, without paying for or sending data to a hosted platform.

Security operations analysts

Decide which vulnerabilities and alerts to act on, and show the reasoning behind each one.

Threat-intelligence analysts

Investigate indicators, hosting and malware links, with sources and limits kept in view.

Small security and IT teams

Watch the products you run and get a short, ranked list of what to fix.

How it works

It runs on your own machine, and your data stays local.

1 · Collect

Gather public data

Pulls vulnerability records, exploitation data and threat feeds into a local database.

2 · Connect

Rank and link it

Scores each CVE and links it to public exploits, threat reports and documented group activity.

3 · Act

Open the dashboard

See what matters most, look up indicators and add the products you run to your watchlist.
